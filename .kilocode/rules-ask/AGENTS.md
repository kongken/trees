# Ask Mode Rules

## Project Context
This is a Flutter app called "Life Forest" (生命森林) for tracking yearly goals as trees with milestones and tasks.

## Key Concepts
- **Year**: A year with a theme sentence (e.g., "变得更健康")
- **GoalTree**: A goal represented as a tree with growth stages (小树苗 → 小树 → 枝叶繁茂 → 硕果累累 → 大树)
- **Milestone**: A milestone within a goal
- **Task**: Tasks can be habits, one-time, or deadline-based
- **GoalLog**: Journal entries and system logs for goals

## Chinese Labels
All enum labels are in Chinese via extension methods (see `lib/models/*.dart`)
